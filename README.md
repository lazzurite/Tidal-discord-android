# TIDAL & HiBy Music — Discord Rich Presence for Android

Полноценный клиент Discord Rich Presence для Android, синхронизирующий статус воспроизведения из **TIDAL** и **HiBy Music** (включая режим Bit-Perfect).

## Возможности
- 🎵 Поддержка плееров **TIDAL** и **HiBy Music**.
- 🖼️ Автоматический поиск и отображение обложек треков (iTunes Search API + Discord Proxy).
- ⏱️ Интерактивный ползунок времени трека.
- ⏸️ Корректное отображение статуса паузы без сброса карточки.
- 🔗 Кнопка быстрого поиска трека на YouTube.
- 🚀 Сетевое ядро на **Go (Golang)** через WebSocket Gateway v10, скомпилированное через `gomobile`.

## Установка
1. Скачайте свежий `.apk` со страницы [Releases](../../releases).
2. Установите приложение на телефон.
3. Выдайте разрешение **Доступ к уведомлениям** (на Android 13/14+ предварительно включите «Разрешить ограниченные настройки» в свойствах приложения).
4. Вставьте ваш Discord Token и нажмите **Сохранить и подключить**.
